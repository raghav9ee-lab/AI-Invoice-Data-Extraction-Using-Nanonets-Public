Organizations receive hundreds of invoices every month. Manual invoice processing is:

- Time consuming
- Error prone
- Costly
- Difficult to scale

AI-powered invoice extraction automates the process and improves accuracy.

## Objective

To automate invoice data extraction from purchase invoices using Nanonets AI OCR.

## Tools Used

- Nanonets OCR
- PDF Invoices
- Microsoft Excel
- GitHub

## Dataset

Sample Purchase Invoice containing:

- Supplier Information
- Purchaser Information
- Item Details
- Quantity
- Unit Price
- Subtotal
- Discount
- Shipping Cost
- Grand Total

## Extracted Fields

### Supplier Details
- Supplier Name
- Supplier Address
- Supplier Email

### Purchaser Details
- Purchaser Name
- Purchaser Address
- Purchaser Email

### Financial Details
- Invoice Number
- PO Number
- Invoice Date
- Payment Terms
- Subtotal
- Discount
- Shipping
- Grand Total

### Item Details
- Item Number
- Description
- Quantity
- Unit Price
- Total

## Results

Successfully extracted:

✔️ Supplier Information

✔️ Purchaser Information

✔️ Payment Terms

✔️ Item Details

✔️ Financial Summary

✔️ Invoice Totals
